## [v0.3.0] - 2026-08-15 ([`3ee1651`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/3ee1651))

### Highlights

- PDLC (Product Development Lifecycle) added as the canonical stage-ID hub: a native six-stage lifecycle splitting each AIDLC phase into parallel product/builder lenses, with a crosswalk other frameworks map their stages onto

### Added

- `PDLCFramework` type and component types (`PDLCPhase`, `PDLCSubStage`, `PDLCDeliverable`, `PDLCGate`, `PDLCDependencies`/`PDLCDependency`, `PDLCTooling`) modeling the six-stage Product Development Lifecycle ([`f297b4c`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/f297b4c))
- Generic `FrameworkRelation`/`StageCrosswalk` types so any two cataloged frameworks can crosswalk through a shared stage-mapping shape instead of a bespoke pairwise mapping type ([`f297b4c`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/f297b4c))
- `frameworks/pdlc/pdlc-framework.json`: six-stage catalog entry with phases (role, `aiDlcPhase`, deliverables, gates, `parallelWith`), Product Definition's seven detailed sub-stages, a dependency graph closing the loop back to `product-definition`, and an AIDLC crosswalk via `relatedFrameworks` ([`e89a454`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/e89a454))
- `PDLC()`, `MustPDLC()`, `PDLCJSON()` accessor functions mirroring the existing `AIDLC()`/`MustAIDLC()` pattern ([`e89a454`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/e89a454))

### Documentation

- Root README catalog table row and Go usage example for PDLC; `frameworks/pdlc/README.md` documents the six-stage model and function reference ([`06bea7a`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/06bea7a))
- New `docs/frameworks/pdlc/index.md` MkDocs page covering the six PDLC stages, AIDLC/ASPM relationships, and Go usage; wired into `mkdocs.yml` nav ([`3ee1651`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/3ee1651))
- PDLC added to the Frameworks Overview table, relationship diagram, comparison matrix, and version/status table ([`3ee1651`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/3ee1651))
- `PDLC()`/`MustPDLC()`/`PDLCJSON()` and the generic `FrameworkRelation`/`StageCrosswalk` types documented in the Go Module API reference ([`3ee1651`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/3ee1651))

### Tests

- `TestPDLC`: 6 phases in canonical order, 2 product/4 builder role split, Product Definition's 7 sub-stages, Builder/Product Operations run in parallel (not sequentially), AIDLC crosswalk symmetry (every AIDLC phase claimed by exactly 2 PDLC stages), dependency graph closes the loop ([`5c6ef72`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/5c6ef72))

## [v0.2.0] - 2026-07-18 ([`72277e2`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/72277e2))

### Highlights

- AIDLC (AI-Driven Development Lifecycle) added as the first Development Lifecycle framework, plus a full MkDocs documentation site

### Added

- AIDLC framework: 3 phases (Inception, Construction, Operations), 12 document deliverables with evaluation criteria, human review gates between phases, LLM cost estimates (~$1.81 per full workflow), dependency graph for document generation order ([`9d0f322`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/9d0f322))
- AIDLC PIDL process specification (`aidlc-workflow.pidl.json`) with input/output data ports, latency budgets (P50/P95/P99), failure modes, and retry strategies ([`9d0f322`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/9d0f322))
- `AIDLC()`, `MustAIDLC()`, `AIDLCJSON()` accessor functions and full AIDLC type definitions ([`9d0f322`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/9d0f322))

### Documentation

- MkDocs documentation site with Material theme: homepage, getting started guides, framework docs (AIDLC, ASDM, AI-DORA, AI-SPACE, PBMM), Go API reference, PRISM/VisionSpec/PIDL integration guides, contributing guide ([`72277e2`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/72277e2))

## [v0.1.0] - 2026-06-07 ([`38ad7f5`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/38ad7f5))

### Highlights

- Initial framework catalog release: two original maturity models (ASDM, PBMM) and two AI-adapted metrics frameworks (AI-DORA, AI-SPACE), with a Go module providing typed embedded access

### Added

- ASDM (Autonomous Software Delivery Model) framework spec: 7-level progression from Agile/Scrum to autonomous operations, with AWS Project Mantle (L5) and StrongDM Software Factory (L6) case studies ([`0ef1159`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/0ef1159))
- PBMM (Product Builder Maturity Model) framework spec: 7-level dual-path model (PM path, Engineer path) converging at L5-L6, with framework mappings to AI-DORA and AI-SPACE ([`fc05219`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/fc05219))
- AI-DORA framework spec: 4 metrics (Deployment Frequency, Lead Time, Change Failure Rate, MTTR) with AI-recalibrated elite/high/medium/low thresholds ([`2ebffb2`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/2ebffb2))
- AI-SPACE framework spec: 25 metrics across 5 dimensions (Satisfaction, Performance, Activity, Communication, Efficiency) ([`137bf58`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/137bf58))
- Go module with embedded framework access: `AIDora()`, `AISpace()`, `ASDM()`, `PBMM()` typed accessors, `Must*` variants, `*JSON()` raw-bytes access, `FS()` embedded filesystem ([`4c05c37`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/4c05c37))

### Documentation

- README with framework overview, case studies, Go module installation/usage examples, function reference table, PRISM integration patterns ([`67216c9`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/67216c9))

### Tests

- Framework embedding tests verifying all four frameworks parse correctly, plus `Must*` functions, raw JSON access, and embedded FS ([`88f748d`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/88f748d))

### Internal

- Shared GitHub Actions CI/lint/CodeQL workflows and golangci-lint configuration ([`38ad7f5`](https://github.com/ProductBuildersHQ/productbuildershq-frameworks/commit/38ad7f5))
