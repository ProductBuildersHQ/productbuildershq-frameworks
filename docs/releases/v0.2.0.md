# v0.2.0 Release Notes

**Release Date:** 2026-07-18

This release adds AIDLC as the first Development Lifecycle framework in the catalog, and ships a full MkDocs documentation site.

## Highlights

- AIDLC (AI-Driven Development Lifecycle), adapted from the [AWS AI DLC](https://docs.aws.amazon.com/prescriptive-guidance/latest/ai-driven-software-development/): 3 phases, 12 document deliverables, human review gates, LLM cost estimates
- Full MkDocs documentation site with Material theme, covering all five cataloged frameworks

## What's New

### AIDLC Framework

```go
import frameworks "github.com/ProductBuildersHQ/productbuildershq-frameworks"

aidlc := frameworks.MustAIDLC()
fmt.Printf("AIDLC: %d phases, %d total deliverables\n",
    len(aidlc.Phases), countDeliverables(aidlc))
```

- **Phases:** Inception, Construction, Operations — each with specific deliverables, human review gates, and LLM-as-Judge evaluation criteria (1-5 scale)
- **PIDL process spec** (`aidlc-workflow.pidl.json`): input/output data ports, P50/P95/P99 latency budgets, failure modes, and retry strategies per step
- **Cost estimates:** ~$1.81 estimated LLM cost to generate all 12 documents
- New accessors: `AIDLC()`, `MustAIDLC()`, `AIDLCJSON()`

See the [AIDLC framework page](../frameworks/aidlc/index.md) for the full phase-by-phase breakdown.

### Documentation Site

The MkDocs site (Material theme) now covers:

- Getting Started: installation, quick start
- Frameworks: AIDLC (with per-phase pages), ASDM, PBMM, AI-DORA, AI-SPACE
- Go Module API reference
- Integration guides: PRISM, VisionSpec, PIDL
- Contributing guide
